02 / Session controls

LOCAL VIEW
Had penting
Prototaip ini menggunakan pengecaman pertuturan yang disediakan pelayar. Sokongan Safari dan bahasa berbeza mengikut versi/peranti. Import audio hanya memuatkan fail untuk rujukan; transkripsi fail memerlukan enjin pemprosesan tambahan.

Sumber audio luaran

Untuk audio daripada workstation atau output perisian siaran, sambungkan output itu ke audio interface USB yang dikenali sebagai input mikrofon iPhone/Mac, atau gunakan komputer yang membekalkan audio sebagai input. Safari tidak membenarkan laman web menangkap sebarang audio sistem secara bebas.

Skop prototaip

✓ UI responsif iPhone/iPad/Mac
✓ Pilihan bahasa dan transkrip sementara
✓ Cap masa dan eksport teks
